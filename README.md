## Hi, I’m Michael 👋

I build web apps, design systems and data tools, mostly in TypeScript, with some Go. Most of it is self-hosted on a small VPS with [Dokploy](https://dokploy.com), with Cloudflare in front.

### Live projects

- **[NYC Dataviz](https://nycdataviz.com)**: New York City’s public data on a map, and a report card for any building (violations, evictions, rent regulation, crime, flood risk), plus data stories on rats, trees, landlords and more. Agents can query it too, through an MCP server.
- **[You already pay for it](https://medicareforall.today)**: a Medicare for All cost calculator for households, small businesses and the country. Every number links to its source, and nothing you enter leaves your browser.
- **[Open Mic MPLS](https://openmicmpls.com)**: event management for Minneapolis open mics: artist signups, timeslots and a public schedule. ([code](https://github.com/mcorrigan89/openmic-tanstack))

### Design systems

shadcn registries: you install the components’ source into your project and own it.

- **[Phosphor](https://mcorrigan89.github.io/phosphor/)**: a retro-terminal design system for React. Glowing type, panels and instrument-style readouts for dense dashboards.
- **[Headway](https://mcorrigan89.github.io/headway-ui/)**: a design system after the New York City subway’s signage: black sign bands, route colours, bullets and strip maps. ([code](https://github.com/mcorrigan89/headway-ui))

### Tools

- **[Prototype Comments](https://github.com/mcorrigan89/prototype_comments)**: Figma-style comments for static prototypes, from one script tag. Reviewers pin comments to any element, reply, @mention and resolve threads.
